# UNC (Unified Naming Convention) — заметки для GERKYLES

Стандарт: https://github.com/unified-naming-convention/NamingStandard
Канонический тест: `UNCCheckEnv.lua` в корне репо (скопирован сюда).
UNC официально retired (Script-Ware свернула разработку), но экзекуторы
(включая Real) до сих пор ориентируются на эти сигнатуры.

## Что стандарт требует для функций, которые мы используем

- **getcustomasset(filepath)** — только СТРОКОВАЯ форма (табличной в
  стандарте нет). Возвращает строку `rbxasset://...`. Работает с ЛЮБЫМ
  файлом (тест скармливает текстовый "success") — картинка или текст,
  декодирование на стороне движка. Вывод для нас: если Real возвращает
  валидный rbxasset-URL, а ImageLabel даёт rect 0,0 — файл-контент не
  декодировался как изображение (битые байты/кэш), либо Real кэширует
  ассет по пути — лечится уникальным именем файла на каждую попытку.
- **writefile(path, content)** — на части экзекуторов ТРЕБУЕТСЯ
  расширение в имени файла (тест UNC это проверяет — у нас всегда .png/.jpg ✓).
- **readfile / isfile / makefolder / delfile / listfiles** — стандартный
  файловый набор, delfile есть (можно чистить кэш-ассеты).
- **queue_on_teleport** — алиас queueonteleport; функция-очередь строк,
  исполняемых после телепорта/хопа.
- **request** — алиас http_request; возвращает таблицу с Body (сырые
  байты) — ЕДИНСТВЕННЫЙ корректный способ качать картинки
  (game:HttpGet портит бинарники текстовым декодированием — причина
  пустого фона v2.93, подтверждено живым тестом плиток v3.15).
- **identifyexecutor** — алиас getexecutorname, возвращает имя+версию.

## Практика для GERKYLES

1. Реал отдал `custom asset OK` (строка rbxasset) при rect 0,0 — контент
   дошёл, картинка не декодировалась. Первичный подозреваемый — кэш
   getcustomasset по пути: ретраи делаем с УНИКАЛЬНЫМ именем файла
   (pe_bg_1.png, pe_bg_2.png...), не переиспользуя pe_bg_img.png.
2. `delfile` — чистить старые pe_bg_img.* перед новой загрузкой.
3. Тест окружения: запустить UNCCheckEnv.lua на Real → результат в
   workspace → сразу видно, какие UNC-функции реализованы.

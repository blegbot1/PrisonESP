# Prison ESP + Разведка

Чит для тюремного RP Roblox (заключённые / охрана / преступники).
GUI на Rayfield. Версия **v0.3**. Проверено: `luac -p` — чисто.

## Запуск

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/blegbot1/PrisonESP/main/PrisonESP.lua",true))()
```

## Если что-то не появляется

- **Нет меню**: Rayfield грузится с двух URL по очереди (sirius.menu и
  GitHub). Если оба недоступны — включается простое перетаскиваемое
  меню с основными тумблерами.
- **Нет коробок/стрелок/полосок**: в консоли будет варнинг — значит в
  исполнителе нет библиотеки Drawing; работают подписи и подсветка
  предметов. В консоли при запуске печатается статус:
  `[PE] v0.3 запущен | Drawing=... | Rayfield=...`.

## Что умеет v0.2 (ESP перенесён из BloodyStreetESP v11.53)

- **Роли и цвета**: охрана — синий, зеки — оранжевый, преступники —
  красный. Роль определяется по команде (Teams), атрибутам и
  инструментам (Handcuffs/Taser = охрана, пушка с GunScript_Server =
  преступник). `PE.TeamOf(игрок)` — проверить в консоли.
- **Коробки**: 3D-коробка по габаритам всей модели (облегает тело,
  поворачивается с игроком, дальние рёбра бледнее), стили рамка/
  уголки, отступы (px и студы), толщина, прозрачность, затухание.
- **Визуалы**: скелет (R6+R15), полоска HP с градиентом и вспышкой
  урона, рамка головы, стрелки к игрокам с наконечниками, стрелки
  к целям за экраном, кольцо под целью (рейкаст до пола, только
  когда цель на земле), вектор движения, лёгкий режим, миникарта.
- **Подписи**: метка роли [ОХР]/[ЗЕК]/[КРИМ], оружие, ник, дистанция,
  HP (шт/%), скорость, цвет ника по HP, мёртвые скрываются, игроки
  за спиной не рисуются.
- **ESP предметов на земле**: пушки (AK-74, M16, MP5, SVD, Kord, MG42,
  ППШ, M9), молоток, KeyCard (жёлтый), патроны (зелёный) — сквозь стены.
- **Разведка** (проверка дыр перед боем):
  - `getgenv().PE.Guns()` — ТТХ всех пушек из их Setting-модулей
    (урон, скорострельность, разброс) — модули читаются клиентом.
  - `getgenv().PE.Remotes()` — все ремоуты с путями.
  - `getgenv().PE.Probe("Имя", аргументы...)` — один вызов + 5 секунд
    печати ответов сервера.
  - `getgenv().PE.TeamOf(игрок)` — как скрипт видит роль игрока.

## Что проверять зондом (по дампу игры)

```lua
getgenv().PE.Probe("InflictTarget", workspace["НИК"].HumanoidRootPart) -- урон по чужой части?
getgenv().PE.Probe("ChangeAmmoAndClip", 30, 30)                        -- патроны себе?
getgenv().PE.Probe("ChooseTeamEvent", "Guard")                         -- смена команды?
```

Если InflictTarget принимает чужую часть без проверки — это килл
кого угодно откуда угодно; ChangeAmmoAndClip — вечный магазин;
ChooseTeamEvent — мгновенная смена стороны. Логи из игры → дальше
строим боевые функции.

всех серверных скриптов в `prison_dump_full.txt`.

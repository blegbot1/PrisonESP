# Prison ESP + Бой

Чит для тюремного RP Roblox (заключённые / охрана / преступники).
GUI на Rayfield. Версия **v2.22**. `luac -p` — чисто.

## Запуск

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/blegbot1/PrisonESP/main/PrisonESP.lua",true))()
```

## Что умеет

### ESP (вкладка ESP)
- **Роли**: охрана — синий, зеки — оранжевый, преступники — красный.
  Определяется по команде/атрибутам/инструментам (`PE.TeamOf(ник)`).
- **3D-коробки** по габаритам модели (стили рамка/уголки/3D, отступы,
  толщина, прозрачность, затухание; ближе 7 стадов — скрываются).
- Скелет (R6/R15), полоска HP с градиентом и вспышкой урона, рамка
  головы, трейсеры, стрелки к игрокам за экраном, кольцо под целью
  (выкл по умолчанию), вектор движения, лёгкий режим, миникарта.
- **Детектор админов** — UserId из исходника админ-панели: магента,
  тег [ADMIN], алерт в консоль при входе на сервер.
- Подписи: [GUARD]/[PRIS]/[CRIM], оружие, ник, дистанция, HP, скорость.

### Мир (вкладка World)
- Подсветка пушек/KeyCard/патронов на земле сквозь стены.
- **Опасные зоны**: Death Part — красным, EscapePart (побег) — зелёным.
- **Телепорт к зоне побега** одной кнопкой.
- **Маскировка**: надеть ближайший Outfit (подлёт + клик + возврат).
- Каталог магазина в консоль.

### Бой (вкладка Combat)
- **Килл-аура** — InflictTarget с точной подписурой из исходника
  GunScript_Local: `(Humanoid, Part, урон, направление, отдача,
  вампиризм, поджог)`. Бьёт в голову; урон 1–10000; радиус; задержка;
  7 режимов целей (все/кроме своих/только свои/враги/охрана/зеки/
  выбранный игрок — с кнопкой «ONLY selected player» и печатью имени).
- **Вампиризм** (6-й аргумент = 1000000) — каждый удар ауры лечит:
  псевдо-бессмертие, пока аура бьёт. Вкл по умолчанию.
- **Подброс жертв** (5-й аргумент = 100000 вверх) — флинг.
- **Поджог** (7-й аргумент FlamingBullet) — серверный IgniteScript
  вешает на цель горение (DoT). Вкл по умолчанию.
- **Тазер-аура** — Taser.RemoteEvent:FireServer(ПОЗИЦИЯ): сервер
  станит того, кто у позиции; 5-секундный кулдаун только клиентский,
  обходим (троттл 2.5 с на игрока — не палимся). Кнопка «TASE selected
  player x3». Нужен тазер (GUARD).
- **Фейк-выстрелы** — VisualizeBullet-ретрансляция сервера: все видят,
  как вы стреляете (по выбранной цели кнопкой или под курсор клавишей
  G), урона нет. Психоз-атака.
- **Прокачка пушки** — мутация Setting-модуля (require-кеш общий с
  GunScript_Local): урон, **хедшот ×500** (HeadshotDamageMultiplier),
  **дробовик** (8 пуль/выстрел), **очередь** (10 пуль/клик),
  **взрывные пули** (AoE радиус), **горящие пули**, отдача, piercing,
  авто, без разброса, перезарядка 0.5с, бесконечный магазин.
  Сбрасывается при смене оружия/респавне — нажать снова.
- **Наручники и телепорт** — выбор жертвы из списка: телепорт за
  спину, CuffEvent, комбо, cuff-аура. Handcuffs — за GUARD.
- **Анти-стан** — регдолл/тазер/наручники не держат (проверено по
  исходнику RagdollModule: рвём BallSocketConstraint).
- Смена команды GUARD/PRISONER/ESCAPED (преступники = команда
  «Escaped» из Teams), сброс в меню (выход из наручников).
- **Гивер оружия** — fireclickdetector с подлётом к дальним пушкам;
  «ВЫДАТЬ ВСЁ», открыть все двери камеры.
- **Хоткеи**: K — килл-аура, T — тазер-аура, Y — тазер по выбранному,
  G — фейк-выстрел под курсор.
- Анти-детект: клампы на месте использования, троттлы на игрока
  (поджог/подброс/тазер), ForceField-скип, потолки множителей.

### Консольные отладочные функции
- `PE.Guns()` — ТТХ пушек, `PE.Remotes()` — список ремоутов,
  `PE.GunSource()` — декомпиляция GunScript_Local, `PE.Diag()`,
  `PE.TeamOf(ник)`, `PE.Probe(...)`.

## Технические детали
- Своя копия Rayfield (`rayfield.lua`) грузится первой: окно сразу
  создаётся в PlayerGui (у части исполнителей UI в gethui рисуется,
  но не принимает клики). Фолбэки: sirius.menu → GitHub.
- `CreateWindow` обязательно требует `Name`. Каждый элемент меню в
  своём pcall с варнингом.
- Повторный запуск скрипта корректно убивает предыдущий (PE_Stop).
- Источники знаний: декомпиляция пушек + полный экспорт плейса в
  Studio (save.rbxlx) через официальный Studio MCP (execute_luau).
  Серверные скрипты в копии вычищены (0 байт), клиентские — целые.

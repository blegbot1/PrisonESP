# Prison ESP + Бой

Чит для тюремного RP Roblox (заключённые / охрана / преступники).
GUI на Rayfield. Версия **v2.7**. `luac -p` — чисто.

## Запуск

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/blegbot1/PrisonESP/main/PrisonESP.lua",true))()
```

## Что умеет

### ESP (перенос из BloodyStreetESP v11.53)
- **Роли**: охрана — синий, зеки — оранжевый, преступники — красный.
  Определяется по команде/атрибутам/инструментам (`PE.TeamOf(ник)`).
- **3D-коробки** по габаритам модели (стили рамка/уголки/3D, отступы,
  толщина, прозрачность, затухание; вплотную — скрываются).
- Скелет (R6/R15), полоска HP с градиентом и вспышкой урона, рамка
  головы, стрелки к игрокам, стрелки за экраном, кольцо под целью
  (выкл по умолчанию), вектор движения, лёгкий режим, миникарта.
- Подписи: [ОХР]/[ЗЕК]/[КРИМ], оружие, ник, дистанция, HP, скорость.
- Подсветка пушек/KeyCard/патронов на земле сквозь стены.

### Вкладка «Бой»
- **Килл-аура** — InflictTarget с точной подписурой из декомпиляции
  GunScript_Local: `(Humanoid, RootPart, урон, направление, отдача,
  вампиризм, поджог)` + слайдер урона (10–500) и радиус.
- **Punch-аура** — FistEvent("Punch") с режимом «стоять у цели»:
  телепорт к жертве один раз, удары без возвратов, автопереход к
  следующей цели, возврат домой при выключении.
- **Наручники и телепорт** — выбор игрока из списка: телепорт за
  спину, наручники через CuffEvent (нужны Handcuffs — команда GUARD),
  комбо-кнопка, cuff-аура на ближайшего врага.
- **Анти-стан** — регдолл/тазер/наручники не держат: запрет
  регдолл-состояний, автоподъём, восстановление скорости, снос
  GetTasedBro и отрыв наручников.
- **Бесконечные патроны** — ChangeAmmoAndClip(магазин, 999999)
  раз в секунду (клиент сам так делает при перезарядке).
- **Вечный спринт**, смена команды (GUARD/PRISONER/CRIMINAL),
  сброс в меню (выход из наручников).
- **Гивер оружия** — fireclickdetector с подлётом к дальним пушкам
  и возвратом на место; «ВЫДАТЬ ВСЁ».
- **Открыть все двери (камеры тюрьмы)**.

### Вкладка «Разведка»
- Выбор цели из списка игроков (обновляется сам каждые 5 с).
- Пробы: урон по цели, патроны, смена команды.
- `PE.Guns()` — ТТХ пушек, `PE.Remotes()` — список ремоутов,
  `PE.GunSource()` — декомпиляция GunScript_Local (в pe_gunsrc.txt).
- Безопасные пробы админ-панели (AdminCommandBarEvent молчит —
  сервер проверяет админа) и чтение списка банов.

## Технические детали
- Своя копия Rayfield (`rayfield.lua`) грузится первой: окно сразу
  создаётся в PlayerGui (у части исполнителей UI в gethui рисуется,
  но не принимает клики). Фолбэки: sirius.menu → GitHub.
- `CreateWindow` обязательно требует `Name` (без него Text=nil и
  сборка умирает). Каждый элемент меню в своём pcall с варнингом.
- Диагностика: `PE.Diag()` — дамп ScreenGui/контейнеров; при запуске
  печать статуса Drawing/Rayfield; ошибки VIS-кадра печатаются.
- Простового меню больше нет: только Rayfield; при сбое — варнинг
  в консоль, функции доступны консолью.

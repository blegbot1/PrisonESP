# Prison ESP + Разведка

Чит для тюремного RP Roblox (заключённые / охрана / преступники).
GUI на Rayfield. Версия **v0.1**. Проверено: `luac -p` — чисто.

## Запуск

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/blegbot1/PrisonESP/main/PrisonESP.lua",true))()
```

## Что умеет v0.1

- **ESP игроков**: коробка + имя + оружие в руках + дистанция. Цвета по
  командам: охрана — синий, зеки — оранжевый, преступники — красный.
- **ESP предметов на земле**: пушки (AK-74, M16, MP5, SVD, Kord, MG42,
  ППШ, M9), KeyCard (жёлтый), патроны (зелёный), тазер/наручники.
- **Разведка** (главное в этой версии — проверка дыр перед боем):
  - `getgenv().PE.Guns()` — ТТХ всех пушек из их Setting-модулей
    (урон, скорострельность, разброс) — модули читаются клиентом.
  - `getgenv().PE.Remotes()` — все ремоуты с путями.
  - `getgenv().PE.Probe("Имя", аргументы...)` — один вызов + 5 секунд
    печати ответов сервера.

## Что проверять зондом (по дампу игры)

```lua
getgenv().PE.Probe("InflictTarget", workspace["НИК"].HumanoidRootPart) -- урон по чужой части?
getgenv().PE.Probe("ChangeAmmoAndClip", 30, 30)                        -- патроны себе?
getgenv().PE.Probe("ChooseTeamEvent", "Guard")                         -- смена команды?
```

Если InflictTarget принимает чужую часть без проверки — это килл
кого угодно откуда угодно; ChangeAmmoAndClip — вечный магазин;
ChooseTeamEvent — мгновенная смена стороны. Логи из игры → дальше
строим боевые функции.
